# Kotlin & Android Development

A collection of Kotlin programming exercises and Android applications developed during my Higher Vocational Diploma in Multiplatform Application Development (DAM).

This repository documents my learning journey in Kotlin, Android development, and mobile application programming.

## Projects

| Project | Description |
|---------|-------------|
| 01 - Kotlin Fundamentals | Kotlin syntax, functions, exceptions, scope, and introductory exercises. |
| 02 - Control Structures | Exercises focused on conditional statements, loops, and program flow. |
| 03 - My First App | Introduction to Android application development. |
| 04 - To-Do App | Practice project for building a task management application. |
| 05 - Collage App | Android application for selecting and displaying images in a collage. |

## Technologies

- Kotlin
- Android Studio
- Android SDK
- Gradle
- Java (introductory exercises)

## Getting Started

Clone the repository and open each Android application folder individually in Android Studio. Allow Gradle to synchronize before running the application.
